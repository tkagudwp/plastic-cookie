# 🍪 쿠키 타이쿤 (Cookie Tycoon) - 대규모 17단계 & 모바일 지원판

마우스 클릭, 키보드 숫자 패드(NumPad), **모바일 스마트폰 화면 터치**로 초코칩 쿠키를 굽고, 17단계에 걸친 우주급 제빵 도구와 시설을 해금하며 **천상 승화(Ascension)**를 통해 은하계 쿠키 제국을 건설하는 방치형 클리커 게임입니다.

---

## 📱 모바일(스마트폰) 지원
* **화면 어디를 눌러도 쿠키 생성**: 스마트폰 브라우저에서 쿠키 버튼뿐만 아니라 중앙 화면 전체를 가볍게 탭해도 즉시 쿠키가 구워집니다.
* **멀티 터치 (Multi-touch) 지원**: 양손 엄지, 두 손가락, 세 손가락으로 다다닥 연타하면 각 손가락 위치마다 정확히 쿠키가 구워집니다!
* **더블 탭 확대 방지**: 모바일 환경에서 빠른 연타 시 화면이 확대되거나 스크롤이 흔들리지 않도록 최적화되었습니다.

---

## 🌟 천상 승화(Ascension) 기준 상향
* **승화 최소 기준**: 기존 5만 쿠키 ➔ **누적 1,000,000 (100만) 쿠키 이상**으로 상향 조정되었습니다.
* 중후반 6~7단계 이상의 장비와 시설을 갖추고 본격적인 쿠키 생산 궤도에 올랐을 때 첫 승화의 쾌감을 맛볼 수 있도록 밸런스를 개선했습니다.
